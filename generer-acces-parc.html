Créer l'accès du chef de parc

Un code qui n'ouvre que la gestion du parc, rien d'autre.

Comment ça marche

1Vous tapez votre mot de passe habituel, celui qui ouvre le dossier. Il reste sur ce téléphone, il n'en sort pas.
2La page extrait le parc (véhicules, fiches conducteur, nom de la société) et le referme sous le code du chef de parc. Le reste, registre du personnel, dossier de l'affaire, audits, n'y entre jamais.
3Vous récupérez un fichier, dossier-parc.js, et vous nous le renvoyez. Nous le mettons en ligne, et le code du chef de parc est actif.
